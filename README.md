# 頭痛診斷與預防用藥審查

偏頭痛與頭痛疾患（Migraine & headache）的 ICHD-3 引導式診斷，以及健保給付與學會指引的預防用藥審查互動網頁。

線上版：https://yht5582-source.github.io/Migraine--Headache/

## 功能

1. **ICHD-3 引導式診斷**
   - SNNOOP10 危險徵象篩檢（提示先排除次發性頭痛）。
   - 發作次數、持續時間、位置、性質、強度、活動加劇、噁心嘔吐、畏光怕吵、前兆（類型與 6 項特徵）、自律神經症狀。
   - 每月頭痛天數、偏頭痛天數、持續月數、急性藥物使用天數。
   - 自動判定並逐條標示準則：1.1 無前兆偏頭痛、1.2 前兆偏頭痛（含偏癱性、腦幹、視網膜亞型）、1.3 慢性偏頭痛、2 緊縮型頭痛、3.1 叢發性頭痛、8.2 藥物過度使用頭痛，以及 1.5 可能偏頭痛等。
2. **預防治療與給付評估**
   - 依健保藥品給付規定第一節（115.8.21 更新）逐條判定：Botox 1.6.2.1 第 7 項、CGRP 單株抗體 1.6.5（galcanezumab、fremanezumab）、topiramate 1.3.2.3 第 2 項。
   - 支援首次申請、療程後續用（每月頭痛天數降低 ≥ 50%）與停藥後再次申請（半年限制）。
   - 學會建議：AHS 2021 預防治療適應症、台灣頭痛學會 2017、AHS 2024（CGRP 標靶治療為第一線選項）、EHF 2022。
   - 依開始日產生 CGRP 與 Botox 健保療程時間表。
3. **用藥速查與文獻**。
